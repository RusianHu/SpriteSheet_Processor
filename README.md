# Sprite Sheet Processor (精灵图紧凑化拼接工具)

精灵图的裁剪定位有点麻烦，让我们换个思路，裁掉所有边界和瓦片间隔的透明区域，把每个瓦片按照尺寸紧凑的拼接起来，变成一个新的精灵图，在利用资源的项目中按照尺寸比例裁剪，这不就方便多了（偷懒）？

## 功能特性

*   加载 PNG 格式的精灵图。
*   支持选择预设的网格尺寸（4x4, 3x4, 4x3）来分割精灵图。
*   自动检测并裁剪每个精灵的实际内容区域。
*   将裁剪后的精灵紧凑地排列到新的精灵图上。
*   预览处理后的精灵图。
*   保存处理后的精灵图为 PNG 文件。

## 依赖

*   Python 3.x
*   `tkinter` (Python 标准库，通常已包含)
*   `Pillow` (PIL 的分支，用于图像处理)

## 安装

1.  确保你已经安装了 Python 3.x。
2.  安装 Pillow 库：
    ```bash
    pip install Pillow
    ```

## 如何运行

1.  下载 `SpriteSheet_Processor.py` 文件。
2.  在终端中运行 Python 脚本：
    ```bash
    python SpriteSheet_Processor.py
    ```

## 使用方法

1.  运行程序后，会打开一个 GUI 窗口。
2.  点击“加载精灵图”按钮，选择你的 PNG 精灵图文件。
3.  在“选择网格尺寸”区域，选择与你的精灵图布局匹配的网格尺寸。
4.  点击“处理图片”按钮。程序将根据选定的网格分割图片，并进行紧凑处理。
5.  处理完成后，你可以在“预览”区域看到结果。
6.  点击“保存结果”按钮，选择保存新精灵图的位置和文件名。
